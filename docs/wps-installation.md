# XSTARS Windows WPS 版安装与使用指南

本文档介绍如何在 Windows 环境下安装、配置与使用独立的 **XSTARS for WPS** 发行版。

---

## 1. 支持版本与系统基线

- **操作系统**：Windows 10 / Windows 11 x64
- **WPS 版本正式支持（阻断验收基线）**：
  - WPS Office 365 / 12.x 64 位（专业版、商业版、政企版、教育高级版）
  - 实测基线版本：WPS 365 教育高级版 `12.1.0.28022` 64 位
- **WPS 个人版定位（Beta / 尽力支持）**：
  - 个人版作为 Beta 预览支持（个人版因授权与加载项策略差异，部分环境可能需要手动确认加载项权限；个人版专有问题不阻断专业版首发）。
- **完全离线运行**：
  - 整个分析、写回与导出流程完全在本地运行（仅监听本地回环 `127.0.0.1`），无任何云端依赖或外网请求，符合实验室数据合规与涉密安全要求。

---

## 2. 架构概览

XSTARS for WPS 采用独立的双组件架构：

1. **WPS 官方 JS 加载项（Ribbon + JavaScript）**：提供原生功能区（Ribbon）操作界面，负责选区读取、数据校验、表格写回与图表插入。
2. **本地回环服务（Python Broker & Worker）**：后台常驻 `127.0.0.1:3892`（支持动态端口迁移），每台电脑安装时自动生成独立 Bearer Token 进行鉴权，通过独立 Worker 主线程调度统计计算与 Tkinter 参数对话框。

---

## 3. 离线安装步骤

### 步骤一：运行安装包

1. 下载并运行 `XSTARS_WPS_Setup.exe`。
2. 安装器为当前用户单用户安装（无需管理员提权，默认安装路径为 `%LOCALAPPDATA%\XSTARS-WPS`）。
3. 安装器会自动完成以下配置：
   - 释放后台 Python 服务及运行环境到 `{app}\service`；
   - 自动在 `%USERPROFILE%\.xstars\wps_service.json` 中建立或继承安全令牌（Bearer Token）；
   - 在 Windows 登录项中注册后台服务自启动（`HKCU\...\Run`）；
   - 释放官方离线加载项包到 `{app}\addin\deploy`。

### 步骤二：首次启动服务与加载项配置

1. 安装完成后，安装器会自动在后台启动本地回环服务进程 `xstars-wps.exe serve`（默认监听 `127.0.0.1:3892`）。
2. 在开始菜单点击 **“安装或管理 WPS 加载项”**（或安装结束时勾选对应选项）：
   - 安装助手会在本地临时启动回环发布服务（`127.0.0.1:3890`）并自动在默认浏览器中打开官方加载项发布页：

     ```text
     http://127.0.0.1:3890/publish.html
     ```

3. 在页面中找到 **“xstars-wps-addon”**，点击 **【安装】**（或 **【升级】**）。
4. 助手程序在后台会自动检测加载项安装，并将本机的独立安全令牌（Bearer Token）实时同步到 WPS 加载项配置目录。
5. 安装完成后关闭助手窗口，打开或重启 WPS 表格（ET），顶部功能区即会出现 **“XSTARS”** 标签页。
6. 若日后安全令牌或端口发生变动，可随时在开始菜单运行 **“同步 WPS 加载项配置”** 一键更新配置。

## 4. 功能使用与工作流

1. **一键分析（Run / Quick Run）**：
   - 选中数据区域（包含分组列与数值列）。
   - 点击功能区的 **“Quick Run”** 立即执行分析并生成统计图表；或点击 **“Run”** 弹出参数配置对话框微调配色、柱状图样式与显著性标记。
2. **实验预设（WB / qPCR / CCK-8 / ELISA）**：
   - **Western Blot** / **qPCR**：支持标准分组及多指标标签（Label）自动检测与拆分出图。
   - **ELISA** / **标准曲线**：支持通过原生选区提示框（`InputBox`）分别框选标准品区域与待测样本区域，自动完成四参数拟合与浓度反算。
3. **高清图表导出**：
   - 选中工作表中由 XSTARS 生成的图表（Shape）。
   - 点击功能区 **“Export High-Res”**。
   - 在弹出的原生保存对话框中选择导出路径，支持导出 **PNG / TIFF / JPG / PDF** 四种格式，以及 **96 / 300 / 600 DPI** 自定义分辨率（采用 XSTARS 高保真 Python 重渲染管线，确保无损失真实细节输出）。

## 5. 升级与卸载

### 升级

- 直接运行新版 `XSTARS_WPS_Setup.exe` 进行覆盖安装。
- 安装前会自动将现有 WPS 加载项配置备份至 `%LOCALAPPDATA%\XSTARS-WPS\backup\backup_<时间戳>\`。
- 安装器会自动继承 `%USERPROFILE%\.xstars\wps_service.json` 中的现有安全令牌与端口，用户个性化设置（`%USERPROFILE%\.xstars\settings.json`）与历史数据保持完好。
- 覆盖安装后，若加载项版本有更新，点击开始菜单 **“安装或管理 WPS 加载项”** 并在页面中点击 **【升级】** 即可。

### 卸载

1. **卸载 WPS 加载项**：
   - 打开开始菜单 **“安装或管理 WPS 加载项”**（或运行 `xstars-wps-helper.exe install-page`）。
   - 在打开的页面中找到 `xstars-wps-addon`，点击 **【卸载】** 或 **【禁用】**。
2. **卸载服务与本体**：
   - 在 Windows **“设置” → “应用” → “安装的应用”**（或控制面板）中找到 **“XSTARS for WPS”** 并点击卸载。
   - 卸载程序会自动：
     - 安全终止后台服务进程（`xstars-wps.exe`）；
     - 移除开机自启动注册表项；
     - 清理 `{app}` 安装目录；
     - 用户备份文件保留在 `%LOCALAPPDATA%\XSTARS-WPS\backup` 中以备查验。
   - 保持用户的原始 Excel / VBA 与其他第三方加载项配置完好无损。

## 6. 安全、网络与 EDR 说明

1. **完全离线与网络范围**：
   - 仅使用两个本地回环（Loopback）端口：
     - **3892**（默认）：后台 Python 统计计算与 Worker 调度 Broker（严禁监听 `0.0.0.0` 或外部网络）；
     - **3890**（按需）：由加载项管理助手交互时临时监听，用于向 WPS 宿主提供官方离线部署包。
   - 无任何外网连接、云端上传或远程遥测，实验数据完全不出本机。
2. **代码签名与安全软件（EDR / Windows Defender）提示**：
   - 本安装包与二进制程序由 PyInstaller 和 Inno Setup 离线打包生成。若未导入组织内部专用代码签名证书，首次运行 Windows SmartScreen 或企业级 EDR 可能提示“未知发布者”，属于正常现象，点击“更多信息”→“仍要运行”即可。

## 7. 故障诊断与常见问题

| 现象 / 错误码 | 原因分析 | 解决方案 |
| --- | --- | --- |
| **Ribbon 提示“服务未启动或连接超时”** | 本地 Python 服务未在后台运行 | 检查任务管理器中是否有 `xstars-wps.exe` 进程；可在开始菜单点击 **“XSTARS WPS 后台服务”** 重新启动。 |
| **端口冲突（Port Conflict / Exit Code 2）** | 默认端口 `3892` 被其他程序占用或双开 | XSTARS 服务采用单实例保护，重复启动时自动退出；服务会自动尝试端口迁移并将当前可用端口记录于 `%USERPROFILE%\.xstars\wps_service.json`。 |
| **Token 鉴权失败（401 Unauthorized）** | 加载项注入的 Token 与服务记录的 Token 不一致 | 重新运行安装包，或检查 `%USERPROFILE%\.xstars\wps_service.json` 文件的完整性。 |
| **日志与诊断文件位置** | 排查具体计算错误或图表生成异常 | 查看 `%USERPROFILE%\.xstars\wps_jobs\`（临时运行目录）与 `%USERPROFILE%\.xstars\settings.json`。 |

## 8. 已知限制与设计说明

1. **高分辨率导出范围**：
   - 由 XSTARS 生成的图表采用数据轻量快照重渲染机制（支持 600 DPI 印刷级矢量与高精位图）；
   - 用户手工粘贴的外来图片走系统剪贴板导出（保留原始分辨率并提供插值放大）。
2. **多实例与上下文安全**：
   - 加载项在异步分析返回时会自动校验当前活动工作表（ActiveSheet），若在分析等待期间切换工作表，系统会主动拦截写回以防覆盖错误单元格。
